# 2.0.130 — Unified Operations filter layout

Places sales-person filters and the existing search/stage/contact/card controls
inside the same Filter accordion in manager and supervisor panels. Adds a filter
icon, subtitle, visible chevron and active badge. Uses aligned 44px fields,
consistent teal buttons and responsive grids, with scoped styles overriding
legacy toolbar widths and theme input borders. Expert/executive toolbar behavior
is retained. Existing panel-level JavaScript selectors remain valid.

Validation: inspected markup/helper placement and existing JavaScript selectors.
Visual browser and live WordPress/PHP testing unavailable in this environment.
