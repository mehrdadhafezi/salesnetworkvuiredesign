# نسخه 2.0.53 — پیامک افزایشی و کارت پاپ‌آپی مشتری

## تغییرات

- پیامک صدور و ارسال مجدد فاکتور افزایشی عملیات از همان `payment_pattern` و `payment_template` تنظیمات چرخه فروش استفاده می‌کند.
- متغیرهای پترن پرداخت افزایشی شامل `customer_name`، `option_title`، `amount`، `payment_type`، `invoice_url` و `remaining_amount` است.
- حالت تست پیامک چرخه فروش برای پیامک افزایشی نیز رعایت می‌شود و مسیر متن ساده مستقل حذف شده است.
- استان و شهر ابتدا از متادیتای حساب و سپس فقط از فاکتور مبدأ عضویت مجاز، سفارش ووکامرس مرتبط و پرونده دات همان عضویت خوانده می‌شود.
- کارت‌های پروفایل کوچک شده‌اند؛ جزئیات اعتبار، گزینه افزایشی، انتخاب فعال‌سازی و تاریخ تماس داخل پنجره پاپ‌آپ ادامه پیدا می‌کند.
- پاپ‌آپ با دکمه بستن، کلیک روی پس‌زمینه و کلید Escape بسته می‌شود و تقویم شمسی بالاتر از آن باقی می‌ماند.

## ایمنی

- هیچ جدول یا رکوردی حذف یا بازنویسی نمی‌شود.
- درگاه پرداخت، تأیید مالی، پورسانت، کیف پول، OTP و سیاست زمان انتظار تغییر نکرده‌اند.
- بازیابی موقعیت از جست‌وجوی سراسری شماره تلفن استفاده نمی‌کند و به عضویت احرازشده محدود است.

## پذیرش روی Staging

1. در تنظیمات چرخه فروش یک پترن پرداخت معتبر ثبت و یک فاکتور افزایشی جدید صادر کنید؛ لاگ فراز باید همان کد پترن را نشان دهد.
2. «ارسال مجدد لینک پرداخت» را هم آزمایش کنید و استفاده از همان پترن را بررسی کنید.
3. برای مشتری فاقد متادیتای موقعیت، استان/شهر فاکتور مبدأ، سفارش ووکامرس و پرونده دات را به‌ترتیب آزمایش کنید.
4. روی دسکتاپ و موبایل چند کارت را باز کنید؛ عملیات باید فقط داخل پاپ‌آپ نمایش داده شود.
5. انتخاب فعال‌سازی توسط کارشناس و تقویم شمسی را داخل پاپ‌آپ ارسال کنید.
6. پرداخت افزایشی، بازگشت از درگاه و سوابق پرداخت مشتری را دوباره آزمایش کنید.
