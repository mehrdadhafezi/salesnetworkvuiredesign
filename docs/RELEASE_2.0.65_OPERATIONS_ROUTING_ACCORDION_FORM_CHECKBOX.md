# Sales Network 2.0.65 — Operations Routing, Accordion & Form Checkbox Fix

- Explicit Sales Manager → Operations Sales Supervisor product routes now stop in the supervisor queue. They never auto-skip to the sole expert.
- All Operations case cards in manager/supervisor/expert sales panels plus executive manager and execution expert panels are collapsed accordions by default.
- Dynamic execution-form checkbox fields have compact checkbox UI, explicit unchecked `0` submission, checked `1` submission, and browser/server required validation.
- Existing manager-only automatic routing behavior remains backward compatible.
- Wallet/commission behavior is intentionally unchanged in this release.
