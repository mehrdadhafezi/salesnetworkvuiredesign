# نسخه 2.0.93 — حفظ تعداد تخصیص

## تغییر انجام‌شده

- پس از تخصیص موفق، مقدار «تعداد شماره به هر گیرنده» پاک نمی‌شود و برای تخصیص بعدی باقی می‌ماند.
- انتخاب گیرنده‌ها و شماره‌های انتخاب‌شده پس از تخصیص موفق همچنان پاک می‌شود تا تخصیص تکراری ناخواسته رخ ندهد.
- رفتار در پنل‌های مدیر/معاون فروش، سرپرست و مسیر عمومی تخصیص یکسان‌سازی و کنترل شد.

## سازگاری و ایمنی

- هیچ تغییری در ساختار دیتابیس، رکوردهای قبلی یا منطق سهم مستقل هر گیرنده انجام نشده است.
- فقط وضعیت رابط کاربری فرم تخصیص پس از پاسخ موفق سرور حفظ می‌شود.

## تست‌ها

- بررسی syntax تمام فایل‌های JavaScript با `node --check`.
- اجرای کامل `node tools/static-audit.js`.
- بررسی نبود دستور پاک‌کردن تعداد در مسیر موفق تخصیص و حفظ مقدار پس از تازه‌سازی بخش فرم.
- PHP CLI در محیط ساخت موجود نبود؛ تست کلیکی روی Staging همچنان توصیه می‌شود.
