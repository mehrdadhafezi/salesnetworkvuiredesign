# انتشار 2.0.43 — اصلاح ورود OTP پروفایل مشتری

## اصلاحات

- پس از تأیید موفق کد OTP، هوک عمومی `wp_login` که ممکن بود توسط قالب یا افزونه‌ای دیگر پاسخ AJAX را به redirect/HTML تبدیل کند، از مسیر ورود مشتری جدا شد.
- برای اتصال‌های سفارشی، هوک اختصاصی `sn_customer_portal_login` اجرا می‌شود.
- کد JavaScript پاسخ تخت افزونه و envelope استاندارد `wp_send_json_success/error` را هر دو می‌پذیرد و در خطاهای HTTP کد پاسخ را نمایش می‌دهد.
- اعتبارسنجی nonce، مالکیت حساب مشتری، عضویت پرداخت‌شده، هش کد و سقف تلاش‌ها بدون کاهش محدودیت امنیتی باقی مانده‌اند.

## تست آفلاین

- `node tools/static-audit.js`: PASS
- نحو همه فایل‌های JavaScript با `node --check`: PASS
- PHP CLI و WordPress/MySQL واقعی در محیط تحلیل موجود نبود؛ تست ورود کامل باید روی Staging انجام شود.

## سناریوی پذیرش

1. صفحه `/biawin/` را با یک مشتری دارای عضویت فعال باز کنید.
2. شماره موبایل را وارد و کد OTP را دریافت کنید.
3. کد پیامک‌شده را وارد کنید؛ باید پاسخ JSON موفق و انتقال به پروفایل انجام شود.
4. کد اشتباه، کد منقضی و کد جدید پس از ارسال مجدد را نیز بررسی کنید.
