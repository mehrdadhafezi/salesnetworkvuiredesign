## کنترل‌های هدفمند کد

- تنظیم SMS دعوت پروفایل در Save/Load/UI وجود دارد و پیش‌فرض 1 است.
- خاموش بودن SMS دعوت، ارسال و retry را متوقف و event ثبت می‌کند.
- OTP ورود تغییر نکرده است.
- متای محصول* برای self activation با default سازگار با گذشته اضافه شده است.
- کارت جدید مقدار self activation را Snapshot می‌کند.
- محصول* با self activation خاموش مستقیم وارد زنجیره فروش عملیات می‌شود.
- base credit صفر مسیر normal را در backend نیز مسدود می‌کند، نه فقط UI.
- نمایش اعتبار صفر در پروفایل مشتری حذف شده است.
- خروجی CSV با Nonce و ownership check محافظت می‌شود.
- Payload API اصلی با فیلد جدید ناسازگار تغییر نکرده است.
- HR picker و bulk hierarchy هر دو رابطه مدیر اجرایی -> کارشناس اجرایی را پوشش می‌دهند.

## تست Runtime پیشنهادی پس از نصب روی Staging

1. تنظیم SMS دعوت را خاموش/روشن کنید و یک خرید جدید ایجاد کنید.
2. دو محصول* بسازید؛ یکی با self activation روشن و یکی خاموش.
3. برای محصول خاموش، کارت باید بدون انتخاب مشتری وارد فروش عملیات شود.
4. محصول* با credit=0 باید در پروفایل «اعتبار 0» نشان ندهد و normal route نداشته باشد.
5. در HR یک کارشناس اجرایی عملیات را زیر مدیر اجرایی عملیات قرار دهید.
6. در یک پرونده wallet/API، CSV خروجی بگیرید و ستون‌ها را با Payload مقصد تطبیق دهید.
