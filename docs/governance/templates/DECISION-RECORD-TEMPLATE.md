# Decision record template

Copy this template to create a decision record.

**Rules:**
- A record stays **DRAFT — NOT APPROVED** until every approval field is filled from verifiable evidence:
  signed minutes, a signature, or an approval comment by the named approver on the PR that commits the
  record.
- Never fill an approval field on someone's behalf.
- Never infer approval from code, tests or merged PRs.
- An approval creates a new version; earlier versions are kept and linked (append-only history).
