# R6-B — فهرست وارسی آمادگی برای تمرین محیط آزمایش با دادهٔ واقعی

**این تمرین انجام نشده و این سند مجوز انجام آن نیست.** هیچ دادهٔ واقعی‌ای خوانده، استخراج، منتقل یا نگهداری
نشده است.

**پیش‌شرط استفاده از این فهرست:** ADR #18 در وضعیت `APPROVED_VERIFIED` باشد (G1) و پیاده‌سازی ابزار مجاز شده
باشد (G2). بخش ۴ از `r6b-m1-adr18-decision-pack-fa.md` را ببینید.

**نحوهٔ پر کردن:**
- هر ردیف را مسئول همان نقش با مرجع مدرک پر می‌کند.
- همهٔ ردیف‌ها باید پر شده و توسط فردی مستقل راستی‌آزمایی شوند.
- فقط پس از آن، اجرای مشخص و محدود (G3) با **مجوز جداگانه برای همان اجرا** ممکن است.
