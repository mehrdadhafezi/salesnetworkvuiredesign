# R6 — Management decision tracker / ردیاب تصمیم‌های مدیریتی

**Every decision below is unapproved.** The tracker is generated from the R5 DRAFT records
(`docs/governance/r5-evidence-index.json`, the R5 packages) and from `docs/governance/r6-decision-tracker.json`,
which holds the lifecycle status. The columns «نتیجهٔ تصمیم» (decision outcome) are empty and stay empty until a
verified approval record exists (`r6-approval-evidence-standard.md`). No approver name is recorded. Role names are
copied from R5 unchanged.

**همهٔ تصمیم‌های زیر تأییدنشده‌اند.** ستون «نتیجهٔ تصمیم» خالی است و فقط با سند تأیید راستی‌آزمایی‌شده پر می‌شود.
