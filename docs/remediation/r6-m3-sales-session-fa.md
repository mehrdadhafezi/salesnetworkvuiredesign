# R6 — جلسهٔ M3: فروش و اختیار موجودی/فاکتور

**هیچ تصمیمی در این سند گرفته نشده است. Production همچنان NO-GO است.**

**قواعد جلسه:**
- تصمیم فقط با امضای نقش‌های تأییدکنندهٔ تعیین‌شده معتبر است. مالک مخزن کد به‌طور خودکار مجاز به تأیید همهٔ
  تصمیم‌های سازمانی نیست؛ اختیار هر امضاکننده باید جداگانه مستند شود.
- توصیهٔ مهندسی فقط کمک به تصمیم است و جایگزین تصمیم نیست.
- نتیجه در «فرم تأیید تصمیم» (`r6-approval-form-fa.md`) ثبت و طبق `r6-approval-evidence-standard.md` راستی‌آزمایی
  می‌شود. برگزاری جلسه، تولید این سند، قبول‌شدن آزمون‌ها یا ادغام Pull Request هیچ وضعیتی را تغییر نمی‌دهد.
- پس از تأیید، پیاده‌سازی و فعال‌سازی هرکدام مجوز جداگانه دارند (`r6-engineering-followup-map.md`).

**قواعد ایمنی موجودی که هیچ تصمیمی آن‌ها را تضعیف نمی‌کند:**
- تلفن فقط برای جست‌وجوست.
- فروشندهٔ اصلی، مالک اعتبار، متولی فعلی، اقدام‌کنندهٔ بعدی و اقدام‌کنندهٔ رویداد هرگز یکی نمی‌شوند.
- اتحاد همهٔ پیوندهای معتبر، وابستگی مالی را تعیین می‌کند.
- پرونده‌های لغوشده هرگز خودکار آزاد نمی‌شوند.

هیچ فرمان نوشتنی فروش فعال نمی‌شود.

**ADR-01 یک پروتکل پیشنهادی (candidate) است و تأیید نشده است.** آزمون رقابتی R4 شاهد فنی مصنوعی است، نه تأیید.

**پیامد کسب‌وکاری در برابر پیامد مهندسی:** هر برگهٔ تصمیم، ریسک کسب‌وکاری و اثر بر پیاده‌سازی را جدا نشان می‌دهد.

**قابل تصمیم‌گیری اکنون (4):** ADR-01, OPD-03, OPD-10, D-29 / D-31.

**نیازمند شواهد بیشتر (4):** F01, D-28, D-32, D-30.
- F01: گزارش پوشش منابع روی دادهٔ واقعی (پس از ADR #18).
- D-28: نسخهٔ 2.0.176 که به آن ارجاع شده در مخزن نیست.
- D-32: قرارداد چرخهٔ عمر صورت‌حساب.
- D-30: گزارش ادغام روی دادهٔ واقعی.
