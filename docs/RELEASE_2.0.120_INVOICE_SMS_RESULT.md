# 2.0.120 — تشخیص و نمایش نتیجه پیامک

- ارسال ساده فراز قبلاً فقط status=OK را موفق می‌دانست و پاسخ مستند status=success را رد می‌کرد. پاسخ موفق اکنون برای ارسال ساده و الگو یکسان پردازش می‌شود.
- HTTP موفق بدون وضعیت موفق در JSON، موفقیت محسوب نمی‌شود.
- پیام سرویس در شکست فراز، پس از پاک‌سازی و حذف کلید اتصال و رمز، به نتیجه صدور منتقل می‌شود.
- در خطای ارتباط، نتیجه «نامشخص» گزارش می‌شود؛ ارسال خودکار تکراری اضافه نشده است.
- خطای اتصال و کد خطای کاوه‌نگار و ملی‌پیامک نیز به کاربر گزارش می‌شود.
- پنل فروشنده پیام دقیق را به جای متن عمومی نمایش می‌دهد و آن را پس از جابجایی به تب فاکتورها نگه می‌دارد.
- پذیرش درخواست سرویس به معنی تأیید تحویل به گوشی نیست.

بررسی syntax جاوااسکریپت، آزمون ایستای افزونه، و آزمون نمایش پیام موفق/ناموفق و escaping اجرا شدند. PHP اجرایی، حساب سرویس و وردپرس زنده در محیط توسعه موجود نیست؛ علت خطاهای واقعی سایت بدون نتیجه سرویس مشخص نیست.
