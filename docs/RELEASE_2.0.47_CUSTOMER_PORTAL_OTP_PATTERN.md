# انتشار 2.0.47 — پترن OTP پروفایل مشتری

## تشخیص

پاسخ 502 فعلی از خود افزونه صادر می‌شد: مسیر ورود مشتری پیامک متن ساده را با `SN_SMS::send()` می‌فرستاد و در صورت پاسخ ناموفق سرویس‌دهنده، عمداً HTTP 502 برمی‌گرداند.

## تنظیمات جدید

در «شبکه فروش ← تنظیمات ← پیامک ← فراز اس‌ام‌اس» دو فیلد اضافه شد:

- کد پترن ورود پروفایل مشتری
- نام متغیر کد در پترن ورود

پترن باید یک متغیر حاوی کد شش‌رقمی داشته باشد. اگر نام متغیر در پنل فراز `code` است، مقدار پیش‌فرض را تغییر ندهید. اگر نام دیگری مانند `verification-code` تعریف شده، همان نام دقیق ثبت شود.

## رفتار ارسال

- برای سرویس‌دهنده فراز، OTP مشتری فقط با پترن اختصاصی ارسال می‌شود.
- ارسال متن ساده به‌عنوان fallback انجام نمی‌شود.
- فقط یک درخواست با timeout ده ثانیه به endpoint پترن ارسال می‌شود.
- کد پترن خالی با پیام تنظیماتی مشخص و HTTP 422 پاسخ داده می‌شود.
- شکست API پترن با پیام مشخص و HTTP 503 پاسخ داده می‌شود.
- OTP ناموفق حذف می‌شود و کد تأییدنشده در سیستم باقی نمی‌ماند.

## پذیرش

1. نسخه 2.0.47 را نصب و کش‌ها را پاک کنید.
2. در تب پیامک، سرویس‌دهنده فراز، API Key، شماره فرستنده، کد پترن ورود و نام متغیر کد را ثبت کنید.
3. پترن فراز باید تأیید و فعال باشد.
4. از صفحه پروفایل مشتری درخواست کد بدهید و دریافت پیامک را بررسی کنید.
5. همان کد را وارد و انتقال به پروفایل را کنترل کنید.
