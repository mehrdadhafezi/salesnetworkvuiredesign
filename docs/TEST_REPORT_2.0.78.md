## محدودیت محیط تست

PHP CLI و WordPress/MySQL اجرایی در این محیط نصب نبود؛ بنابراین `php -l` و Smoke Test واقعی زیبال باید روی Staging اجرا شود. تحلیل ایستا، Parser داخلی پروژه و Syntax Check جاوااسکریپت کامل و موفق بوده‌اند.

## Smoke Test پیشنهادی Staging

1. خروجی جامع درگاه را با Token معتبر و سپس با Token نامعتبر دانلود کنید؛ هر دو باید CSV برگردانند و حالت دوم فقط داده محلی داشته باشد.
2. برای دو فروشنده زیر دو مدیر فروش متفاوت، دو فاکتور بسازید و Snapshot شماره کارت را مقایسه کنید.
3. یک فاکتور قدیمی دارای Snapshot را بعد از تغییر تنظیم کارت باز کنید؛ شماره آن نباید تغییر کند.
4. تب رفتار مشتری را با هر سه نقش باز و یک فاکتور خارج از Scope را امتحان کنید؛ دسترسی باید رد شود.
5. کارت‌به‌کارت را خاموش کنید؛ دکمه مشتری و بارگذاری سرپرست باید حذف/مسدود شود، پرداخت آنلاین و بررسی فیش‌های قبلی باید فعال بماند.
