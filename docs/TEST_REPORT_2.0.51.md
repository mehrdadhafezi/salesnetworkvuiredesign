PHP CLI و WordPress/WooCommerce/MySQL زنده در این محیط وجود ندارد؛ بنابراین `php -l` و تست end-to-end پنل، cron و درگاه باید روی Staging اجرا شود.

## تست دستی Staging

1. در پنل مدیر، چند کارت را بدون فیلتر انتخاب و به سرپرست مستقیم تخصیص دهید.
2. جستجو یا فیلتر وضعیت اعمال کنید و «انتخاب همه نتایج فیلترشده» را بزنید؛ فقط کارت‌های visible باید ارسال شوند.
3. همان سناریو را در پنل سرپرست برای کارشناسان مستقیم تکرار کنید.
4. سرپرست یک کارت را به خودش تخصیص دهد و هر سه وضعیت جواب‌نداده، تماس مجدد و انصراف را آزمایش کند.
5. کارشناس نیز همان وضعیت‌ها را تست کند؛ انصراف بدون دلیل و تماس مجدد بدون تاریخ/ساعت باید رد شوند.
6. یک کارت عادی را به اجرا ارجاع دهید و یک کارت افزایشی را تا پرداخت کامل/برگشت به عادی تست کنید.
