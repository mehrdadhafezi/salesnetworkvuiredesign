## 1. Method and reconciliation

1. All operations were enumerated from `api/openapi/openapi.bundled.yaml` (`paths` × HTTP method): **105 operations** (92 `GET`, 13 `POST`; no `PUT` / `PATCH` / `DELETE`).
2. Each `operationId` was resolved to its strict-server Go handler (`func (…) <OperationId>(`) under `internal/`, excluding `_test.go`, the generated `oapi.gen.go` and the `apiserver/unconfigured.go` fallback (which answers every surface BLOCKED when it is not composed). **105 / 105 resolved; 0 unresolved; 0 handlers without an operation.**
3. The capability was read from the `identityapi.Cap…` identifiers in each handler body, or from the package guard where the handler delegates (payments read `guardOp` → `payments.attempt.read`; identity → `identity.user.read`; write-back → `integration.writeback.read`; finance review → `finance.review.read`).
4. "Scope assertion" = whether the handler (or its package `guardOp`) refuses an allowed decision whose `Decision.Scope != ORGANIZATION` (F-02). Verified by locating `ScopeOrganization` checks: present only in `commission/http/http.go:77`, `reporting/http/http.go:109`, `finance/http/http.go:71`, `biawin/http/http.go:69`, `fulfillment/http/http.go:63`.
5. "Seller row predicate" = whether rows are already restricted to the caller by a server-side predicate.

The reproducible enumeration script is not committed (audit only). Re-run: list `paths` from the bundled spec and grep each `operationId` (first letter upper-cased) as a method name under `internal/`.

**Exports and free-text search:** no export operation and no free-text / phone search parameter exists in any of the 105 operations (list parameters are enum filters + `cursor` + `limit`). Export and search are therefore **NOT APPLICABLE today** and are future surfaces that must carry SR-01 / SR-08 when introduced. **Pagination** is cursor-based; `PageInfo` is `{next_cursor, has_more}` — **no list returns a total count**. Counts exist only in report / aggregate endpoints (rows marked "aggregate").

## 5. Limits of this audit

- Static evidence only; no runtime request was made.

- Generated-code routing (`oapi.gen.go`) was trusted to map each `operationId` to the method of the same name; it was not traced line by line.
- Production deployment configuration is not in the repository (see F-07).
