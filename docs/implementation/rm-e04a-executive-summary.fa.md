# RM-E04A — خلاصهٔ مدیریتی: قرارداد خواندن محدود به فروشنده و معماری امنیتی

**فقط مستندات. هیچ کد، API، migration، پیکربندی، مجوز یا داده‌ای تغییر نکرده است. هیچ تصمیمی تأیید نشده است. تولید: NO-GO.**

## ۱. یافتهٔ اصلی

- امروز ارزیاب مجوز فقط دو دامنه می‌شناسد: «هیچ» و «کل سازمان». هر کس قابلیت خواندن داشته باشد، **کل سازمان** را می‌بیند (F-01).
- **خطر پنهان اصلی (F-02، شدت بالا):** از ۹۲ عملیات GET، در **۵۱** مورد handler بررسی نمی‌کند که دامنهٔ تصمیم مجوز «کل سازمان» باشد. امروز این بی‌خطر است، چون دامنهٔ محدودتری وجود ندارد. اما **به محض** اینکه دامنهٔ «فقط مال خودم» برای فروشنده اضافه شود، این نقاط (پرونده‌ها، متولی، فاکتورها، پرداخت‌ها، مشتریان و تلفن‌ها) داده‌های کل سازمان را برمی‌گردانند. اصلاح این مورد **پیش‌نیاز** هر دامنهٔ محدود است و به هیچ تصمیم کسب‌وکاری نیاز ندارد.
- **F-07 (متوسط، سخت‌سازی):** پاسخ‌های موفق داده سرآیند `Cache-Control: no-store` ندارند. در پیکربندی staging هیچ کش پروکسی وجود ندارد. پیکربندی تولید در مخزن نیست و راستی‌آزمایی نشده است. **ادعای نشت فعال نمی‌شود.**
- **F-09 (کم تا متوسط):** نقطهٔ «زمینهٔ ثبت پرداخت» برای فاکتور فروشندهٔ دیگر ۲۰۰ برمی‌گرداند، اما برای فاکتور ناموجود ۴۰۴. یعنی وجود فاکتور لو می‌رود (بدون مبلغ). امروز هیچ‌کس این قابلیت را ندارد.
- **هیچ نشت فعالی ادعا نمی‌شود:** امروز بستهٔ نقش فروشنده خالی است و هیچ grant فعالی برای فروشنده ممکن نیست.

## ۲. پوشش

| مورد | نتیجه |
|---|---|
| عملیات‌های بررسی‌شده | **۱۰۵ از ۱۰۵** (۹۲ GET، ۱۳ POST)؛ همه به handler واقعی تطبیق داده شدند |
| GET بدون بررسی دامنه | ۵۱ |
| GET با دادهٔ سازمانی بدون فیلتر فروشنده | ۳۷ |
| خروجی (export) و جست‌وجوی متنی | امروز وجود ندارد (موضوعیت ندارد) |
| آزمون‌های منفی مشخص‌شده | **۲۴** (NT-01 تا NT-24)؛ هیچ‌کدام اجرا نشده‌اند |

## ۳. وضعیت هفت صفحهٔ فروشنده

| صفحه | وضعیت |
|---|---|
| S1 شماره‌های من | قرارداد کامل — اجرا مسدود (رکورد پیشنهادی ۱ و ۲ M2) |
| S2 آماده‌های تبدیل | ناقص — «آمادهٔ تبدیل» در سرور منبع ندارد |
| S3 نیاز به اقدام مجدد | مسدود — منبع سروری ندارد |
| S4 فاکتورها | قرارداد کامل — اجرا مسدود؛ «مبلغ تأییدشدهٔ مالی» قاعدهٔ مالی لازم دارد |
| S5 رفتار مشتریان | مسدود — منبع سروری ندارد |
| S6 درخواست شماره | مسدود — OPD-10 |
| S7 کیف پول من | قرارداد کامل — دامنهٔ «فقط خودم» در سرور **وجود دارد**؛ معنای تسویه مسدود (D-41 / OPD-09) |
