# نسخه ۲.۰.۱۵۴ — غیرفعال‌کردن جایزه پرداخت

قابلیت «ثبت شماره دریافت‌کننده جایزه» در صفحه فاکتور به‌طور کامل غیرفعال شد:

- فرم ثبت شماره، دکمه، پنجره جایزه، پیام قبل/بعد پرداخت و برچسب جایزه محصول نمایش داده نمی‌شوند.
- تنظیم قدیمی محصول یا داده قدیمی فاکتور امکان فعال‌کردن این بخش را ندارد؛ بروزرسانی رابط، عناصر قدیمی جایزه را هم حذف می‌کند.
- درخواست مستقیم AJAX ثبت شماره رد می‌شود؛ ثبت جدید و ارسال پیامک جایزه انجام نمی‌شود.
- مسیر داخلی پیامک جایزه پیش از ساخت درگاه یا درخواست شبکه، وضعیت disabled برمی‌گرداند؛ برای فراز و کاوه‌نگار بررسی شده است.
- فعال‌کردن جایزه از ویرایش محصول و جدول گروهی محصولات حذف شده و فیلدهای تنظیمات پیامک/متن جایزه غیرفعال هستند.
- سابقه شماره‌های قبلی در گزارش مدیریتی باقی است؛ داده‌های قبلی حذف نمی‌شوند.

دامنه این تغییر همان قابلیت جایزه پرداخت و فرم معرفی دریافت‌کننده در تصویر است. قرعه‌کشی، گردونه مستقل و کد تخفیف عادی محصول، قابلیت‌های جداگانه‌اند و در این نسخه حفظ شده‌اند. انتخاب تاریخ تماس نسخه ۲.۰.۱۵۳ و تنظیمات درگاه پیامکی نسخه ۲.۰.۱۵۲ نیز حفظ شده‌اند.

اعتبارسنجی: ۹۷ بررسی PHP درگاه/پیامک و غیرفعال‌بودن جایزه، ۵۸ بررسی DOM با اجرای JavaScript واقعی و داده قدیمی فاکتور، ۹۳ بررسی تنظیمات پیامک، ۱۳۵ بررسی تاریخ تماس و ۶۶ بررسی اطلاعات زنده کارت پاس شد. همه ۳۳ فایل PHP از نظر syntax و فایل JavaScript تغییرکرده از نظر parse بررسی شدند. ممیزی عمومی همان پنج ایراد پیشین را گزارش می‌کند و خطای جدیدی ندارد.

نصب روی سایت زنده و ارسال واقعی پیامک انجام نشده است.
