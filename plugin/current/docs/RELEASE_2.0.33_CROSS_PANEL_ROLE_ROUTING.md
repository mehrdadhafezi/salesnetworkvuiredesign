# نسخه 2.0.33 — یکپارچگی نقش و پنل‌های فروش

این نسخه یک بازبینی ایستا روی مسیرهای فروشنده، تبدیل‌کننده، سرپرست، سرپرست ارشد، مدیر فروش، معاون فروش، مالی، منابع انسانی و MIS انجام می‌دهد.

## اصلاح‌ها

- نقش‌های `sn_senior_supervisor`، `sn_sales_deputy`، `sn_hr`، `sn_mis` و `sn_finance` در فعال‌سازی افزونه ثبت می‌شوند.
- نگاشت نقش به سمت در resolver کامل HR، resolver سریع ورود، Scope و Migration یکسان شده است.
- کاربران role-only یا کاربران دارای پروفایل HR ناقص دیگر به‌خاطر نبود fallback به پنل نامشخص هدایت نمی‌شوند.
- fallback آدرس پنل برای سرپرست ارشد، معاون فروش، HR، MIS و مالی تکمیل شده است.
- منوی پرتال برای نقش‌های فعلی سرپرست ارشد و معاون فروش fallback مستقیم دارد.
- فهرست نقش‌های فرانت برای حذف admin bar و سخت‌سازی capabilityها کامل شده است.
- تغییر سمت از پنل HR فقط نقش‌های عملیاتی متعلق به همین افزونه را همگام می‌کند؛ نقش‌های عمومی وردپرس و نقش‌های ناشناخته حذف نمی‌شوند.
- هنگام خروج از سمت مالی، مجوزهای پیش‌فرض مالی باقی نمی‌مانند؛ هنگام ورود به سمت مالی، مجوزهای پایه مشاهده/تأیید/رد پرداخت اعمال می‌شوند.
- فهرست کاربران مالی و گزارش کاربران بدون پروفایل HR نقش‌های جدید را هم پوشش می‌دهد.
- سه endpoint تنبل سرپرست، سرپرست ارشد و مدیر فروش از نظر nonce و مجوز پنل به تست رگرسیون افزوده شدند.

## ایمنی داده

- هیچ جدول یا ستون موجودی حذف یا rename نشده است.
- هیچ فاکتور، لید، پرداخت، پرونده تبدیل، سابقه HR یا تاریخچه انتساب پاک نمی‌شود.
- نگاشت‌های Migration به‌صورت افزایشی seed می‌شوند.
- همگام‌سازی نقش فقط هنگام Apply موفق تغییر سمت اجرا می‌شود.

## کنترل کیفیت

- `tools/static-audit.js`
- بررسی syntax تمام فایل‌های JavaScript با `node --check`
- parse کامل ۱۷ فایل PHP با grammar رسمی tree-sitter PHP
- بررسی نبودن بایت NUL و خطاهای whitespace در diff

تست نهایی رفتار WordPress/WooCommerce/MySQL باید روی Staging دارای نسخه PHP 8 انجام شود.
