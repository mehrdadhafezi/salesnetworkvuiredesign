# 2.0.121 — فروش مستقل محصول*

- شرط عضویت محصول* در محتوای اشتراک فعال از اعتبارسنجی صدور پیش‌فاکتور حذف شد.
- در تنظیمات شبکه فروش هر محصول، گزینه «نمایش محصول* برای فروش مستقل در پنل فروش» اضافه شد. مقدار پیش‌فرض برای محصولات موجود روشن است.
- گزینه خاموش، محصول* را از فهرست فروش مستقل حذف می‌کند و ثبت پیش‌فاکتور جدید مستقل با همان محصول را نیز مسدود می‌کند.
- این گزینه روی محتوای اشتراک، ارتقاها یا فعال‌سازی فاکتورهای پرداخت‌شده اعمال نمی‌شود.
- ساخت کارت پس از پرداخت نیز از الزام اشتراک جدا شد. فروش مستقل فاقد اشتراک با source_type=product_star و subscription_product_id=0 ذخیره می‌شود؛ شناسه خود محصول، نام، اعتبار، قواعد ارتقا و مسیر مسئول در رکورد کارت و snapshot حفظ می‌شوند.
- تنظیم عمومی «نمایش در شبکه فروش» و انتشار محصول همچنان برای فهرست فروش لازم‌اند.

بررسی ایستای کامل افزونه قبول شد. مسیرهای صدور، فهرست محصولات و ساخت کارت بررسی شدند. PHP CLI و وردپرس زنده در محیط موجود نیستند؛ صدور و پرداخت واقعی روی سایت اجرا نشده است.
