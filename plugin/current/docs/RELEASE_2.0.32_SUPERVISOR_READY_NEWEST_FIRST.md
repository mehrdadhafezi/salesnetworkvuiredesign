# نسخه 2.0.32 — ترتیب صف تبدیل سرپرست

- لیست «آماده‌های تبدیل» پنل سرپرست بر اساس `created_at` پرونده مرتب می‌شود؛ جدیدترین ورودی ابتدا نمایش داده می‌شود.
- زمان نمایش‌داده‌شده کنار شماره پرونده نیز همان زمان ورود به صف تبدیل است.
- انتخاب اشتراک، تخصیص تبدیل‌کننده، تغییر وضعیت یا ویرایش‌های بعدی ترتیب صف را جابه‌جا نمی‌کنند.
- هیچ داده، سابقه، فاکتور یا پرداختی تغییر یا حذف نمی‌شود؛ این نسخه فقط ترتیب خواندن و نمایش را اصلاح می‌کند.
