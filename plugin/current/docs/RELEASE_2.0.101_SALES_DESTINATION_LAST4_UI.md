# نسخه 2.0.101 — چهار رقم کارت مقصد و رابط ثبت واریز

## تغییرات

- فروشنده، تبدیل‌کننده و سرپرست برای ثبت اطلاعات واریز فقط ۴ رقم آخر کارت مقصد را وارد می‌کنند.
- ثبت و جایگزینی فیش در پنل تبدیل‌کننده و سرپرست از داخل یک پنجره مرتب انجام می‌شود و ورودی‌های شلوغ از جدول حذف شده‌اند.
- فرم‌های ثبت واریز دارای چیدمان دو ستونه، عنوان و راهنمای روشن و نسخه واکنش‌گرا برای موبایل هستند.
- پنل تأیید مالی کارت مقصد را با عنوان «۴ رقم آخر کارت مقصد» نمایش می‌دهد.
- مسیر ارسال مجدد فاکتور برگشتی فروشنده نیز فقط ۴ رقم آخر کارت مقصد می‌گیرد.

## ایمنی داده

- ستون‌ها و مقادیر کامل کارت مقصد که در نسخه‌های قبلی ذخیره شده‌اند حذف یا بازنویسی گروهی نمی‌شوند.
- برای ثبت جدید، مقدار ۴ رقمی در ستون‌های سازگار قبلی ذخیره می‌شود.
- اگر ۴ رقم واردشده با اسنپ‌شات کامل همان فاکتور تطبیق داشته باشد، اسنپ‌شات کامل موجود فقط برای سازگاری داخلی حفظ می‌شود؛ رابط‌ها همچنان فقط ۴ رقم آخر را نمایش می‌دهند.
- هیچ مهاجرت تخریبی دیتابیس در این نسخه وجود ندارد.
