# انتشار 2.0.77 — بارگذاری فیش توسط سرپرست

- هندلر قدیمی و تکراری جاوااسکریپت که قبل از ارسال فیش خطا می‌داد حذف شد.
- فاکتورهای پرداخت مرحله‌ای با وضعیت `partial_paid` نیز دکمه ثبت فیش دارند.
- فیش فقط برای فاکتورهای درون محدوده HR/تیم همان سرپرست پذیرفته می‌شود.
- فاکتورهای نهایی‌شده، پرداخت‌شده، لغوشده یا بایگانی‌شده در سمت سرور بلاک می‌شوند.
- برای فیش موجود، امکان جایگزینی قبل از تأیید مالی حفظ شده است.

## ملاحظات سازگاری

این انتشار تغییر schema ندارد، داده‌های فعلی را بازنویسی نمی‌کند و مسیر تأیید مالی فعلی را حفظ می‌کند.
