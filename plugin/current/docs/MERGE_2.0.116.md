# ادغام نسخه 2.0.116

پایهٔ مشترک 2.0.108 با بستهٔ CRM نسخهٔ 2.0.113 و بستهٔ ارسالی کاربر نسخهٔ 2.0.115 به‌صورت سه‌طرفه ادغام شد.

- تغییرات CRM قبلی شامل CRM-01 تا CRM-18، CRM-20 تا CRM-23 و CRM-30، CRM-44 و CRM-45 حفظ شدند. CRM-19 و CRM-24 همچنان کنار گذاشته شده‌اند.
- تغییرات 2.0.115 شامل تنظیم نمایش ارتقاهای محصول* در پروفایل، ارتقای بدون پرداخت با مبلغ صفر، حفاظت حذف پروندهٔ MIS، و محاسبهٔ مجدد پورسانت سوابق حفظ شدند.
- تنها تداخل‌های متنی در شمارهٔ نسخه/شناسهٔ ساخت و انتهای CSS رخ داد؛ هر دو به‌صورت دستی رفع شدند. افزودنی‌های هر شاخه در مقایسه با پایه در خروجی حضور دارند.
- کنترل ایستا و syntax جاوااسکریپت اجرا شده‌اند. PHP CLI و محیط وردپرس/دیتابیس برای آزمون عملی اینجا در دسترس نیستند.
