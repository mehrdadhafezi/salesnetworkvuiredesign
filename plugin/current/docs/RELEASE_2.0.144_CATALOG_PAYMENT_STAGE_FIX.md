# نسخه ۲.۰.۱۴۴ — تکمیل اصلاح پرداخت تخفیف‌دار

- مبلغ خالص `final_total` مرجع پرداخت آنلاین برای فاکتور دارای تخفیف کاتالوگ است.
- `product_price`، `payment_total_amount`، مانده و مبلغ سررسید فاکتورهای قدیمی ۲.۰.۱۴۲ با مبلغ خالص همگام می‌شوند.
- رکورد مرحله پرداخت فعال در `sn_invoice_payment_stages` نیز برای فاکتورهای تخفیف‌دار قدیمی اصلاح می‌شود تا callback درگاه به دلیل اختلاف مبلغ رد نشود.
- قبل از ایجاد درخواست درگاه، یک کنترل runtime نیز مبلغ مرحله پرداخت را با مبلغ قابل پرداخت فاکتور تطبیق می‌دهد.
- مبلغ قبل از تخفیف فقط در `original_total` و snapshot تخفیف حفظ می‌شود.
