# نسخه 2.0.80 — عنوان پرداخت، تصاویر و تقویم مشتری

- عنوان مرحله تأیید پرداخت فرم `[sn_dot_marketing_form]` از نام همان محصول ووکامرس خوانده می‌شود. مبلغ همچنان از قیمت همان محصول خوانده می‌شود.
- تصویر محصولات در کارت‌های پروفایل و سربرگ پنجره جزئیات داخل قاب عمودی با نسبت عرض به ارتفاع ۲:۳ نمایش داده می‌شود. کل تصویر با `object-fit: contain` قابل مشاهده می‌ماند؛ تصویر منبع بریده نمی‌شود.
- «فعال‌سازی توسط کارشناس» به بخش جمع‌شونده با توضیح و کنترل تاریخ خوانا تبدیل شد.
- تقویم شمسی شناور بالاتر از لایه پنجره کارت نمایش داده می‌شود و انتخاب تاریخ در فیلد فرم ثبت می‌گردد. تنظیمات ظاهری تاریخ روی موبایل جداگانه تنظیم شد.

بررسی نهایی لازم روی سایت: فرم پرداختی با محصول مشخص، تصویر کارت و جزئیات روی عرض موبایل، باز شدن تقویم و ثبت تاریخ تماس، و نمایش درخواست در پنل فروش عملیات.
