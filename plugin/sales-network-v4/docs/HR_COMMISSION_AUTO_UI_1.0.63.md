# HR Commission Auto UI 1.0.63

این نسخه UI مدیریت نیروها را با منطق ارث‌بری خودکار پورسانت هماهنگ می‌کند.

- ستون «مشمول پورسانت» با «رفتار پورسانت» جایگزین شد.
- حالت پیش‌فرض: خودکار از قوانین مالی بر اساس سمت/سطح.
- قانون دستی فقط در حالت استثنا استفاده می‌شود.
- ذخیره گروهی حقوق/پورسانت نیز override mode را نگه می‌دارد.
