# نسخه 2.0.36 — ترتیب تصمیم‌های اعتبارسنجی

- عنوان «پیامک انتخاب اشتراک» به «ارسال پیامک نتیجه اعتبارسنجی» تغییر کرد.
- عنوان بخش مسئول تبدیل به «ارسال برای سرپرست / تبدیل توسط خودم» تغییر کرد.
- گزینه «ارسال برای سرپرست ارشد» با توجه به مالکیت جدید صف به «ارسال برای سرپرست» اصلاح شد.
- تا زمانی که فروشنده ارسال یا عدم ارسال پیامک نتیجه اعتبارسنجی را انتخاب نکند، گزینه‌های مسیر تبدیل غیرفعال می‌مانند.
- فرم جدید هم در مرورگر و هم در سرور انتخاب صریح هر دو تصمیم را کنترل می‌کند.
- فرم‌های قدیمی کش‌شده که نشانگر نسخه جدید را ندارند، برای جلوگیری از شکست ناگهانی فلو با رفتار سازگار قبلی پردازش می‌شوند.

## تست پذیرش

1. محصول اعتبارسنجی را انتخاب کنید؛ هیچ گزینه‌ای نباید از پیش انتخاب شده باشد.
2. پیش از انتخاب وضعیت پیامک، هر دو گزینه مسیر تبدیل باید غیرفعال باشند.
3. پس از انتخاب «ارسال شود» یا «ارسال نشود»، مسیر تبدیل فعال شود ولی انتخاب پیش‌فرض نداشته باشد.
4. ارسال فرم بدون هرکدام از دو تصمیم، در کلاینت و سرور رد شود.
5. هر چهار ترکیب پیامک و مسیر تبدیل جداگانه تا پرداخت و تأیید مالی آزمایش شوند.
