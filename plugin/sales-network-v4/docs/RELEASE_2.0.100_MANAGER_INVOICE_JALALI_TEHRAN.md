# نسخه 2.0.100 — تاریخ فاکتورهای مدیر فروش و سرپرست

## اصلاح

- ستون «تاریخ» در جدول فاکتورهای محدوده مدیر فروش دیگر مقدار خام میلادی دیتابیس را نمایش نمی‌دهد.
- تاریخ‌های ایجاد، پرداخت، تأیید و آخرین ویرایش در پاسخ API به‌صورت فیلد نمایشی جلالی و با ساعت تهران آماده می‌شوند.
- جدول‌های مدیر فروش و سرپرست فقط از فیلدهای نمایشی جلالی/تهران استفاده می‌کنند.
- تاریخ‌های ذخیره‌شده و سوابق قبلی تغییر یا بازنویسی نمی‌شوند.

## سازگاری

این تغییر فقط لایه نمایش را اصلاح می‌کند و هیچ مهاجرت دیتابیس یا تغییری در منطق فاکتور، پرداخت و تأیید مالی ندارد.
