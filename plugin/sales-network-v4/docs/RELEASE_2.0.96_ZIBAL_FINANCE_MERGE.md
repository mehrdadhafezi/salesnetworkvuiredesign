# نسخه 2.0.96 — ادغام پنل مالی زیبال و اصلاح پیامک تبدیل

این نسخه تغییرات شاخه خروجی مالی زیبال را به‌صورت انتخابی روی نسخه 2.0.95 ادغام می‌کند و هیچ‌یک از اصلاحات پیامک فاکتور یا پرداخت بعد از تبدیل را جایگزین نمی‌کند.

## پنل تأیید مالی و زیبال

- انتخاب ستون‌های خروجی در تب پرداخت درگاهی؛ هر 28 ستون به‌صورت پیش‌فرض انتخاب‌اند.
- افزودن شناسه‌های فروشنده، سرپرست و سرپرست ارشد و نام/شناسه مدیر فروش و معاون فروش.
- ارسال `merchantId` تنظیم‌شده افزونه در درخواست اصلی Report API زیبال، بدون وابستگی به MU patch.
- پشتیبانی از فیلدهای واقعی `terminalNumber`، `cardHolderIP` و `psp`.
- خروجی CSV با BOM واقعی UTF-8 و حفظ شناسه‌ها، موبایل، شماره کارت و تاریخ‌ها در Excel.
- عددی ماندن ستون‌های مبلغ برای جمع، مرتب‌سازی و فیلتر Excel.
- ادامه خروجی از پرداخت‌های موفق داخلی CRM هنگام اختلال API زیبال.

## اصلاحات حفظ‌شده

- ارسال مجدد پیامک فاکتور برای نقش‌های مجاز.
- بازیابی امن پیامک لینک پرداخت بعد از تبدیل.
- ثبت‌نشدن پیش‌نمایش حالت تست به‌عنوان پیامک واقعی.
- رعایت تنظیم روشن/خاموش کارت‌به‌کارت در پیامک.

## ایمنی

خروجی مالی فقط خواندنی است، هیچ مهاجرت دیتابیس ندارد و داده‌های قبلی را تغییر نمی‌دهد. ستون‌های ارسالی با allowlist سمت سرور اعتبارسنجی می‌شوند و خروجی شناسه‌محور در برابر فرمول‌های دلخواه CSV محدود شده است.
