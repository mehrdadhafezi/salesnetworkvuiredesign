# نسخه 2.0.54 — بازطراحی پروفایل و کارت‌های مشتری

## تغییرات رابط

- ارتفاع هدر پروفایل، شاخص‌ها و اطلاعات هویتی کاهش یافته و فاصله‌ها یکدست شده‌اند.
- هر اشتراک با هدر کوتاه، نام واضح، تاریخ فعال‌سازی و وضعیت مستقل نمایش داده می‌شود.
- کارت‌ها از حالت بسیار ریز قبلی خارج شده‌اند و در عین جمع‌وجوربودن، تصویر، نام، وضعیت، نوع فعال‌سازی و اعتبار خوانا دارند.
- عبارت داخلی «فلو عملیات» حذف و وضعیت واقعی مانند «در انتظار انتخاب مشتری»، «در حال پیگیری کارشناس» یا «تکمیل‌شده» نمایش داده می‌شود.
- هر کارت فقط یک اقدام اصلی «جزئیات و ادامه» دارد و تمام انتخاب‌ها داخل پاپ‌آپ انجام می‌شوند.
- پاپ‌آپ دسکتاپ به‌صورت پنجره مرکزی و در موبایل به‌صورت شیت پایین صفحه نمایش داده می‌شود.
- کنترل فوکوس صفحه‌کلید، Escape، بستن با پس‌زمینه و بازگشت فوکوس به کارت اضافه شده است.

## موارد حفظ‌شده

- منطق فعال‌سازی عادی، افزایشی و فعال‌سازی توسط کارشناس تغییری نکرده است.
- انتخاب تاریخ شمسی، پیامک پترنی پرداخت افزایشی، استان/شهر، سوابق پرداخت و تاریخچه حفظ شده‌اند.
- هیچ تغییر مخرب دیتابیس یا بازنویسی سابقه وجود ندارد.

## پذیرش روی Staging

1. پروفایل دارای یک، دو و چند کارت را در عرض‌های دسکتاپ، تبلت و موبایل بررسی کنید.
2. متن نام طولانی کارت نباید از قاب خارج شود و وضعیت و اعتبار باید خوانا بمانند.
3. هر کارت باید پاپ‌آپ خودش را باز کند و عملیات کارت دیگری را نمایش ندهد.
4. پاپ‌آپ با ضربدر، پس‌زمینه و Escape بسته شود و فوکوس به دکمه همان کارت برگردد.
5. فعال‌سازی عادی، افزایشی، درخواست کارشناس و تقویم شمسی را داخل پاپ‌آپ اجرا کنید.
