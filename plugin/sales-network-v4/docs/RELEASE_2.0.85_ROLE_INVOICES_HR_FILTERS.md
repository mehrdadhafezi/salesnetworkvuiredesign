# Release 2.0.85 — Role invoices and HR filters

## تغییرات

- فاکتورهای پرداخت تبدیل، بدون تغییر مالکیت تاریخی داده، برای کاربری که تبدیل را انجام داده یا لینک پرداخت را صادر کرده در تب فاکتورها نمایش داده می‌شوند.
- فروشنده‌ای که تبدیل را خودش انجام داده، فاکتور تبدیل خودش را در فاکتورها می‌بیند؛ فاکتور تبدیل سایر نقش‌ها برای او نمایش داده نمی‌شود.
- فروشنده فقط می‌تواند اطلاعات واریز را ثبت کند. آپلود فیش در UI و کنترل سمت سرور برای فروشنده مسدود است.
- سرپرست و تبدیل‌کننده مجاز می‌توانند اطلاعات واریز یا فیش را ثبت کنند؛ تمام عملیات در سمت سرور با محدوده فاکتور کنترل می‌شود.
- فیلترهای سریع سمت، سطح، وضعیت و نوع همکاری و مرتب‌سازی صعودی/نزولی به جدول HR اضافه شد.
- «انتخاب همه» فقط ردیف‌های قابل مشاهده پس از جستجو و فیلتر را انتخاب می‌کند و ردیف‌های مخفی را از انتخاب خارج می‌کند.
- دامنه «همه ردیف‌های قابل مشاهده» در ذخیره گروهی HR نیز از روی ردیف‌های واقعاً قابل مشاهده ساخته می‌شود.
- نتایج query نیروها و گزینه‌های مدیر بالادستی در همان درخواست cache می‌شوند تا query تکراری به ازای هر ردیف حذف شود.

## سازگاری داده

- هیچ جدول یا رکورد قبلی حذف یا بازنویسی نمی‌شود.
- `seller_id` فاکتور تبدیل برای گزارش‌ها و پورسانت‌های قبلی دست‌نخورده می‌ماند؛ نمایش نقش انجام‌دهنده از `issued_by_user_id` و لینک پرونده تبدیل خوانده می‌شود.
- وضعیت‌ها و مراحل پرداخت موجود حفظ می‌شوند و ثبت جدید از همان مسیر تأیید مالی استفاده می‌کند.
