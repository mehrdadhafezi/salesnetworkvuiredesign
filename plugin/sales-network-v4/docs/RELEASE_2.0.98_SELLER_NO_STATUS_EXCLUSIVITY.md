# نسخه 2.0.98 — خروج صحیح از تب «بدون تعیین وضعیت»

## اصلاح انجام‌شده

- پرونده‌ای که برای آن وضعیت فروشنده ثبت شده است دیگر هم‌زمان در تب «بدون تعیین وضعیت» نمایش داده نمی‌شود.
- شرط تب و شمارنده آن اکنون هر دو مقدار وضعیت را بررسی می‌کنند:
  - وضعیت استاندارد و ماشینی فلو فروشنده (`seller_flow_status`)
  - وضعیت نمایشی/قدیمی (`lead_status`)
- شماره‌های درخواستی همچنان در تب مستقل «درخواست شماره» قابل مشاهده‌اند، اما پس از تعیین وضعیت از تب «بدون تعیین وضعیت» خارج می‌شوند.

## سازگاری و ایمنی داده

- هیچ جدول، ستون یا رکوردی تغییر یا حذف نشده است.
- مهاجرت دیتابیس لازم نیست.
- داده‌های قدیمی که فقط وضعیت نمایشی دارند و داده‌های جدید که وضعیت استاندارد دارند هر دو درست تشخیص داده می‌شوند.
